# Panijog

Hydration-tracking Android app (version 1.0) and its static marketing website.

- **App:** native Android, package `com.hanafi.panijog.hytdrk`, minSdk 24.
- **Website:** static HTML/CSS/JS, hosted on Firebase Hosting at
  `https://panijog.web.app/`.
- **Developer:** Mohammadullah Al Hanafi — https://mohammadullah.web.app/
